# Changelog

All notable changes to this project are documented in this file.

## 0.1.0 - 2026-07-18

- Added a project-level income and expense ledger with signed amounts.
- Added CBRF currency catalog and historical exchange-rate synchronization.
- Added project-member and external participants.
- Added optional work package links and project-copy support.
- Added journal history for scalar and association changes.
- Added filtering, sorting, pagination, totals, and RUB conversion.
- Added CSV and XLS exports for the complete filtered result set.
- Added Russian and English translations.
